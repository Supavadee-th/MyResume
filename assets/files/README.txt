================================================================================
Assets: Downloadable Files Directory
================================================================================

This directory stores downloadable documents for the portfolio.

Files in this directory:
- Resume_Supavadee_Junyakul.pdf:
  The official resume PDF for Supavadee Junyakul.
  Linked by the "Download Resume" buttons in:
  1. Navigation Bar (Desktop and Mobile drawer)
  2. Hero Section
  3. Internship Call to Action Banner (Section 10)

How to update the Resume PDF:
1. When you have an updated version of the resume, save it in this directory as:
   'Resume_Supavadee_Junyakul.pdf'
2. If you change the filename, update the variable '$resumePdfPath' in 'includes/header.php',
   '$resumePdf' in 'includes/hero.php', and '$resumePdf' in 'includes/contact.php'.
