================================================================================
Assets: Images Directory
================================================================================

This directory contains image assets used in Supavadee Junyakul's portfolio website.

Files in this directory:
- profile.png:
  The candidate's official portrait photo extracted directly from her resume PDF.
  Displayed in Section 01 (Hero).
  Recommended dimensions: 400x500px or 3:4 aspect ratio.

How to replace or add images:
1. To update the profile photo, place a photo here named 'profile.png' (PNG or JPG).
2. If you use a JPG or different filename, update the 'src' attribute in 'includes/hero.php'
   and Open Graph image in 'includes/header.php'.
3. For project screenshots, save your images here (e.g. 'project-nsc.jpg', 'project-farm.jpg')
   and reference them in 'includes/projects.php'.
